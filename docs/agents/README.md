# Agents

This directory documents the participation of development agents within the RVRS project.

Rather than defining a complete framework from the outset, these documents record the project's current understanding of how agents can contribute to the language and its development.

## Documents

- **00 Current State** — A snapshot of the repository prior to agent participation.
- **01 Agent Initiation** — Records the beginning of agent participation and its initial objectives.
- **02 Agent Operating Principles** — Describes the principles intended to guide agent participation as the project evolves.

For an overview of RVRS itself, see the repository's main `README.md`.
